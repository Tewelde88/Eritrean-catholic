Style Guide

The colors, fonts, spacing and building blocks for the official website of the Catholic Church in Eritrea. Every page of the site should be built from these pieces.

Colors

Marian Blue and Gold. Gold is for lines and ornaments only; use the darker gold for small labels. Every color has a dark-mode version.

Primary--color-primary
Primary text and links--color-primary-text
Gold accent--color-accent
Gold label--color-accent-text
Background--color-bg
Surface (cards)--color-surface
Text--color-text
Soft text--color-text-soft

Typography

Headings use EB Garamond. Reading text uses Source Sans 3. Tigrinya (Ge'ez script) uses Noto Serif Ethiopic and Noto Sans Ethiopic automatically.
